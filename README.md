# Japanese flashcards

The root `index.html` is generated from every other root-level `.html` file.
Add a chapter page to this folder and push it to `main`; the Pages workflow
will regenerate the menu and publish the pages.

In the repository settings, configure **Pages → Build and deployment → Source**
as **GitHub Actions**. The published site is available at
`https://madispoel.github.io/japanese/`.
